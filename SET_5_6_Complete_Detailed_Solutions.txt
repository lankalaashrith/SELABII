Q1 — DOCKER COMPOSE: FLASK API + NGINX
------------------------------------------------------------

(a) Run Flask API and Nginx in separate containers, with Flask on port 5000 and Nginx on port 80.

STEP 1: Check Docker
    docker --version
    docker ps

STEP 2: Go to the FoodSystem project directory.
    cd <FoodSystem-project-directory>
    ls

Look for the Flask application and the Nginx/frontend files.

STEP 3: Create a Dockerfile for Flask if the repository does not already contain one.
Example:
    FROM python:3.11
    WORKDIR /app
    COPY . .
    RUN pip install -r requirements.txt
    EXPOSE 5000
    CMD ["python", "app.py"]

Use the repository's actual Flask start file if it is not app.py.

STEP 4: Build the Flask image.
    docker build -t food-flask .

STEP 5: Create docker-compose.yml.
Use:
    services:
      flask:
        build: .
        container_name: food-flask
        ports:
          - "5000:5000"

      nginx:
        image: nginx:latest
        container_name: food-nginx
        ports:
          - "80:80"

STEP 6: Start both services.
    docker compose up -d

STEP 7: Verify.
    docker compose ps
    docker ps

Expected: both flask and nginx containers are running.

STEP 8: Test Flask.
    curl http://localhost:5000

STEP 9: Test Nginx.
Open:
    http://localhost

If port 80 is already occupied, use a different HOST port such as 8080:
    "8080:80"
Then open:
    http://localhost:8080

(b) Avoid port conflicts when both services run on one Docker host.

Use different HOST ports if another process already owns the required port.

Example:
    flask:
      ports:
        - "5000:5000"

    nginx:
      ports:
        - "80:80"

If port 80 is occupied:
    nginx:
      ports:
        - "8080:80"

Important rule:
HOST_PORT:CONTAINER_PORT

(c) Run both services simultaneously.

STEP 1:
    docker compose up -d

STEP 2:
    docker compose ps

STEP 3:
    docker compose logs

STEP 4:
    curl http://localhost:5000

STEP 5:
    Open Nginx in browser:
    http://localhost

(d) Separate Flask and Nginx containers with host ports 5000 and 80.

The Compose configuration is:
    services:
      flask:
        build: .
        ports:
          - "5000:5000"

      nginx:
        image: nginx:latest
        ports:
          - "80:80"

Start:
    docker compose up -d

Verify:
    docker ps

(e) Complete solution.

Example complete docker-compose.yml:
    services:
      flask:
        build: .
        container_name: food-flask
        ports:
          - "5000:5000"
        networks:
          - food-network

      nginx:
        image: nginx:latest
        container_name: food-nginx
        ports:
          - "80:80"
        networks:
          - food-network
        depends_on:
          - flask

    networks:
      food-network:

Run:
    docker compose up -d

Verify:
    docker compose ps
    docker network ls
    docker network inspect <project-name>_food-network

Useful cleanup:
    docker compose down
    docker compose down --volumes

Do not use --volumes unless you intentionally want to remove Compose-managed volumes.

STEP 1:
    minikube start

Q1 — DOCKER COMPOSE: WORDPRESS + MYSQL
------------------------------------------------------------

(a) Run WordPress and MySQL.

STEP 1:
    docker --version
    docker ps

STEP 2: Create a working directory:
    mkdir cems-compose
    cd cems-compose

STEP 3: Create docker-compose.yml.

Use:
    services:
      db:
        image: mysql:5.7
        container_name: cems-mysql
        environment:
          MYSQL_ROOT_PASSWORD: root
          MYSQL_DATABASE: wordpress
          MYSQL_USER: wpuser
          MYSQL_PASSWORD: wppass

      wordpress:
        image: wordpress:latest
        container_name: cems-wordpress
        ports:
          - "8080:80"
        environment:
          WORDPRESS_DB_HOST: db:3306
          WORDPRESS_DB_USER: wpuser
          WORDPRESS_DB_PASSWORD: wppass
          WORDPRESS_DB_NAME: wordpress
        depends_on:
          - db

STEP 4:
    docker compose up -d

STEP 5:
    docker compose ps

STEP 6:
    docker ps

(b) Host port 8080 -> container port 80.

The required mapping is:
    ports:
      - "8080:80"

Verify:
    docker ps

Then open:
    http://localhost:8080

(c) Configure depends_on.

Inside wordpress:
    depends_on:
      - db

This tells Compose to start the db service before the WordPress service.

Important: depends_on controls startup order; it does not guarantee that MySQL is fully ready to accept connections.

(d) Named volume for persistent MySQL data.

Add:
    volumes:
      - mysql-data:/var/lib/mysql

At the bottom of the Compose file add:
    volumes:
      mysql-data:

Then verify:
    docker volume ls

The volume stores MySQL data outside the container lifecycle.

(e) Complete Compose file.

Use:
    services:
      db:
        image: mysql:5.7
        container_name: cems-mysql
        environment:
          MYSQL_ROOT_PASSWORD: root
          MYSQL_DATABASE: wordpress
          MYSQL_USER: wpuser
          MYSQL_PASSWORD: wppass
        volumes:
          - mysql-data:/var/lib/mysql

      wordpress:
        image: wordpress:latest
        container_name: cems-wordpress
        ports:
          - "8080:80"
        environment:
          WORDPRESS_DB_HOST: db:3306
          WORDPRESS_DB_USER: wpuser
          WORDPRESS_DB_PASSWORD: wppass
          WORDPRESS_DB_NAME: wordpress
        depends_on:
          - db

    volumes:
      mysql-data:

Run:
    docker compose up -d

Verify:
    docker compose ps
    docker volume ls

Open:
    http://localhost:8080

Stop:
    docker compose down

The named volume remains unless explicitly removed with:
    docker compose down -v
